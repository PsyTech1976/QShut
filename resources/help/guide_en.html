User Guide - QShut

QShut is a lightweight graphical application for Linux designed to easily and securely schedule system power-off, reboot, or suspend operations without requiring administrative privileges (root/sudo).

1. Scheduling Modes

  • Countdown: Set the remaining duration in minutes (from 1 to 10080 minutes). You can use the quick shortcut buttons +15m, +30m, +1h, and +2h to rapidly increment the target timer.
  • Specific Time: Pick an exact time of day (format HH:mm). If the chosen time has already passed for today, the task is automatically scheduled for tomorrow.

2. System Actions

Using the "Action" selector, you can choose:

  • Shut down computer: Safely powers off the computer (default).
  • Restart computer: Reboots the system cleanly.
  • Suspend (Sleep): Puts the system into low-power sleep mode.

3. System Tray & Desktop Notifications

  • Checking "Minimize to system tray" automatically hides the main window when you start the timer.
  • Hovering over the tray icon reveals the live remaining countdown.
  • Clicking the tray icon or selecting "Show Window" from its right-click menu restores the main interface.
60-Second Safety Alert:
When exactly 60 seconds remain before execution, QShut displays a desktop notification and restores the main window to the foreground, giving you a chance to click "Cancel" if you change your mind.

4. Simulation Mode (Test)

Enabling "Simulation mode (Test)" allows you to verify the countdown, notifications, and progress bar without any risk of actually shutting down your system.

5. Command-Line Options

  • ./QShut-x86_64.AppImage --test : Launches with simulation mode enabled by default.
  • ./QShut-x86_64.AppImage --help : Displays command-line options.
  • ./QShut-x86_64.AppImage --version : Prints the version.
